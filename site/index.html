AI 商務簡報

AI 商務簡報 b2b-slide

跟 AI 對話 30 到 60 分鐘，做出能直接上台、文字可以改的商務簡報

你需要具備的環境

  • 自己的電腦：支援 Mac（macOS）或 Windows 作業系統。
  • 一個能讀寫電腦檔案的 AI 工具：推薦 Claude 電腦版 App（https://claude.ai/download），已完整實測；Antigravity 也已完整實測。Codex 等其他能在電腦上執行程式的 AI 工具也能用同一句話安裝，但尚未完整實測。
  • Python 3.10 以上版本：請至官方頁面下載安裝：https://www.python.org/downloads/（Windows 安裝時請務必勾選「Add Python to PATH」）。
特別提醒：網頁版、手機版的 AI 聊天都不能用（包含 Claude、ChatGPT 的網頁版）。本工具需要在你的電腦上讀寫檔案、執行程式。

安裝方式一（推薦，不用會終端機）

打開 Claude 電腦版 App 貼上指令 零指令基礎

打開 Claude 電腦版 App 的「Code」分頁，複製並貼上以下這句話給 AI，AI 便會自動閱讀手冊完成安裝：

請照 https://github.com/fishtvlvoe/b2b-slide 的 INSTALL-FOR-AI.md 幫我安裝 b2b-slide

安裝方式二（會用終端機）

Mac（打開 Terminal 終端機執行）
curl -fsSL https://raw.githubusercontent.com/fishtvlvoe/b2b-slide/main/install.sh | bash
Windows（打開 PowerShell 執行）
irm https://raw.githubusercontent.com/fishtvlvoe/b2b-slide/main/install.ps1 | iex

開始第一份簡報

安裝完成後，在 Claude 電腦版 App 打開你的工作資料夾 b2b-slide-簡報，直接在對話框輸入：

我要做商務簡報
1
訪談
AI 提出針對性商務問題，釐清您的簡報情境、聽眾身份、痛點與核心訴求。
2
中繼稿確認
提煉出條理分明的事實清單與論點大綱，由您檢視確認，確保資訊無遺漏、無虛構。
3
故事地圖
規劃每一頁投影片的邏輯流向、頁面主標與說服層次，確保整體脈絡緊湊。
4
5 頁樣品批註
先行產出 5 頁實際版面樣品，供您在預覽頁審視排版與視覺比重，隨時提出調整建議。
5
完整 PPTX
確認樣品滿意後，正式生成全套原生 PowerPoint 簡報檔，字型、文字與版面均可自由修改。

支援的簡報類型

支援的簡報
  • 客戶提案（商業解決方案）
  • BNI 專題（商會引薦簡報）
  • 公司／產品介紹（業務推廣）
  • 合作邀約（異業戰略結盟）
不支援的類型
  • 內部報告（例行週會、日常進度匯報）
  • 課程簡報（教學培訓、長篇課綱講義）

常見問題

沒有 Python 怎麼辦？
請前往 Python 官方下載頁（https://www.python.org/downloads/）下載最新版安裝程式。特別提醒 Windows 使用者：安裝開始時，請務必勾選畫面下方的「Add Python to PATH」選項，安裝完成後重新開啟 Claude App 即可。
安裝卡住怎麼辦？
本工具安裝程序具有暫存隔離與自我保護設計，所有安裝動作都在獨立暫存資料夾中進行，自我測試完全通過後才會替換。如果因為網路波動中途卡住，直接再次貼上安裝指令重新執行即可；即便安裝失敗，舊有的配置與簡報檔案也會完整保留，不會受損。
預覽頁為什麼是簡體字？
預覽檢視器採用了底層開源排版引擎作者的外框介面，該檢視器本身的標籤為原作者介面；但這完全不影響您的簡報產出，AI 為您製作的訪談、中繼稿、文字內容與最終匯出的 PowerPoint 檔案，全部均為正體繁體中文。
怎麼放自己的照片？
在「5 頁樣品批註」或製作階段，直接把您的照片檔案拖曳放進 Claude 電腦版 App 的對話框中，並告訴 AI「請把這張照片放到第 X 頁」，AI 就會自動將照片儲存至簡報專案目錄，並精確嵌入到對應的投影片版面中。
怎麼更新？
更新方式非常簡單，只需重新在 Claude 電腦版 App 貼上一次安裝句子（請照 https://github.com/fishtvlvoe/b2b-slide 的 INSTALL-FOR-AI.md 幫我安裝 b2b-slide）即可。系統會全自動拉取最新版本並執行自我測試，只有測試通過才會替換；若過程中有任何中斷或失敗，舊版本依然安全保留運作。
