## 3. 選定理由：鎖定 `v4.5.0`

綜合實測結果，決定將 `ppt-master.lock` 鎖定為 **`tag=v4.5.0`**，理由如下：

1. **血緣與黃金案例最契合（某公關行銷公司案例同源）**：
   - 作者本機實測成功產出某公關行銷公司 14 頁高品質提案之版本為 `v4.5.0-38-g4e6ecbcb`。上游正式 tag 中，`v4.5.0` 在渲染底層、版型解析與排版規則上與此黃金案例同源，行為可預期性最高。
2. **匯出效能極高**：
   - v4.5.0 的 PPTX 匯出耗時僅 **0.54 秒**，相較於 v6.7.0 的 1.56 秒快近 3 倍。在學生進行多次樣品迭代與量產時，能提供更流暢的回饋體驗。
3. **架構簡約穩定，符合 Ponytail 原則**：
   - v6.7.0 後期加入了許多進階但本專案不需的複雜功能（如 Image-to-PPTX、LaTeX 渲染、音訊混音剪輯、複雜的 prototype carriers 限制），也更動了 `confirm_ui` 推薦檔的 JSON 結構。v4.5.0 的架構純粹專注於 DrawingML 原生形狀與文字框渲染，最不易受環境變更干擾，對於學生跨平台（macOS / Windows）教學最為穩健。
