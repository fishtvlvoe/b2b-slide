# 01-CORE-METHODOLOGY：破例感官 × 商業提案四步法

> **核心脈絡**：寫程式、寫深度長文、做商業簡報、開線上課程，底層邏輯完全相同——**「不是選三個模板把字塞上去，而是有嚴密的邏輯脈絡由終為始推導」**。

---

## ▋ 一、由終為始：先立【核心觀點】，再推【破題鉤子】

商業簡報與寫作最常見的致命失誤：
- ❌ 開場報戶口流水帳（「大家好我是某某某，今天很高興來到這裡...」）
- ❌ 開場宣告目錄大綱（「今天我將從這四個章節為大家說明...」）
- ❌ 空泛的大道理開場（「數位轉型是現代企業不可或缺的基石...」）

### 正確邏輯：
1. **先鎖定整份簡報的唯一核心觀點（觀）**：
   - 這一份簡報只賣「一個翻轉常識的獨特主張」。
   - 例如某公關行銷公司提案：「不要再追工具；花 6 小時學會一套換工具也不用從頭學的 Skill 工作流」。
2. **從核心觀點回推第一個破題想法（破）**：
   - **鉤子（Hook）**：讓觀眾在 3 秒內被刺痛、停下來。
   - **反差破題**：製造強烈對比。例如：「你想每天都在追新出現的 AI 工具，還是只投資 6 小時？」
   - **群體同溫層刺痛**：直戳對方現狀的隱形代價。

---

## ▋ 二、提出問題：【例】與【感】的肉身場景刻畫

提出問題時，絕對不用抽象形容詞，而是用李思萱老師的**「破・例・感・觀」**法則：

| 零件 | 商業提案中的轉譯 | 寫法關鍵 | 誤區警告 |
| :--- | :--- | :--- | :--- |
| **破** | 為什麼客戶要停下來聽你提案 | 反差鉤子、直切痛點選擇題 | 不要交代公司歷史背景、不要列目錄大綱 |
| **例** | 客戶現在卡關的真實情境 | 一個具體動作、一個日常卡點畫面 | 不要講假大空趨勢、不要堆砌產業專有名詞 |
| **感** | 客戶肉身痛苦與時間浪費 | **硬規則：名詞＋動詞展示痛苦**（如：每次重打指令、熬夜拉框、核對單據到半夜） | 不要只說「很辛苦」、「效率很差」這種形容詞 |
| **觀** | 你的獨特解法與結論落地 | 翻轉常識的一句話商業結論 | 不要喊口號、不要說「我們致力於卓越服務」 |

---

## ▋ 三、商業提案四步順序鐵律（The 4-Step Sequence）

在完成痛點感知後，商業簡報必須嚴格依循此四步推進：

```
┌────────────────────────────────────────────────────────┐
│ 1. 先講結論 (Bottom Line Up Front)                     │
│    - 清楚亮出核心觀點與最終交付價值                    │
│    - 讓對方 30 秒內知道聽完能帶走什麼                 │
└──────────────────────────┬─────────────────────────────┘
                           │
                           ▼
┌────────────────────────────────────────────────────────┐
│ 2. 再來講問題 (The Gap & Pain Point)                   │
│    - 用【例】+【感】（名詞+動詞）描繪現狀卡關          │
│    - 對齊痛點：你們不是不會，是卡在重複勞動與不可複用 │
└──────────────────────────┬─────────────────────────────┘
                           │
                           ▼
┌────────────────────────────────────────────────────────┐
│ 3. 最後講你怎麼做到 (How You Do It)                    │
│    - 具體拆解執行步驟、機制、交付標準、時程與定價      │
│    - 證明這不是黑盒運氣，而是一套可落地的作業系統      │
└──────────────────────────┬─────────────────────────────┘
                           │
                           ▼
┌────────────────────────────────────────────────────────┐
│ 4. 提出誰符合這個情境 (Call to Action / Referral)      │
│    - 誰是你的理想客戶？誰現在正身處上述痛點？          │
│    - 給出「一句話引薦指南」：別人怎麼一句話把你介紹出去│
│    - 當場促成合作、轉介與下一步簽核                    │
└────────────────────────────────────────────────────────┘
```
